AI Habit Tracker is a full-stack, AI-assisted habit tracking application built with Next.js (App Router), TypeScript, Tailwind CSS, and a Python backend. It allows users to log daily habits, visualize progress through dashboards and charts, analyze behavioral breakdowns, and receive AI-driven insights and suggestions for consistency improvement. The app features authentication-protected routes, a stateless navigation system, local-first data storage for fast access, and a clean, modern UI optimized for deployment on Vercel.
